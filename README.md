# Code de la route — site interactif

Site statique en français, compatible GitHub Pages, sans dépendances ni installation.

## Publication sur GitHub Pages

1. Créez un dépôt public sur GitHub, par exemple `code-route`.
2. Décompressez le ZIP et importez **index.html à la racine du dépôt** (README.md facultatif).
3. Dans le dépôt, ouvrez **Settings > Pages**.
4. Sous **Build and deployment**, sélectionnez **Deploy from a branch**, puis la branche **main**, dossier **/(root)** et cliquez sur **Save**.
5. Après publication, le site sera accessible à `https://VOTRE-PSEUDO.github.io/code-route/` (remplacez les deux valeurs).

## Fonctionnalités

- 5 chapitres de cours dépliables
- Mini-quiz de 5 questions avec correction
- Examen blanc d'entraînement de 40 questions avec correction et seuil de réussite
- Suivi des scores en localStorage, sans compte ni serveur
- Affichage adapté au téléphone et à l'ordinateur

**Important :** support pédagogique non officiel. Les 40 questions sont des questions d'entraînement originales, pas des questions officielles de l'examen. Les règles et limites de vitesse doivent être vérifiées sur les sites officiels avant l'examen.
